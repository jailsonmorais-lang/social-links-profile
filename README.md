### O que eu aprendi

Este projeto foi fundamental para eu entender a importância da organização de arquivos no deploy. Tive desafios com o carregamento de imagens e CSS que me ensinaram a:

1. **Caminhos de Arquivos:** Aprendi que no GitHub Pages não devemos usar a barra `/` no início do caminho se o arquivo estiver na mesma pasta.
2. **Case Sensitivity:** Entendi que o servidor diferencia `style.css` de `estilo.css` e que os nomes devem ser idênticos ao código.
3. **Cache do Navegador:** Descobri que usar `Ctrl + F5` é necessário para visualizar mudanças após o deploy.
